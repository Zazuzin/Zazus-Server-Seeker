# Zazu's Server Seeker v0.4.0-beta.1

The first public beta for Minecraft 26.2 and Fabric Loader 0.19.3.

## Highlights

- BreakBlocks, Cornbread and MineScan server discovery.
- Verified Search with two live Minecraft status checks.
- Quick Search for immediate, clearly labelled unverified provider results.
- Favourites, Servers, Scanned Servers and Recent Servers categories.
- Sequential Auto Join for Scanned Servers and established Servers.
- Favourite-safe health cleanup and deletion recovery.
- Single and bulk Undo Last Delete support.
- Optional ViaFabricPlus integration.

## Beta note

This is a beta release. Back up `servers.dat` before testing and report reproducible issues with the Minecraft `latest.log`, the selected Finder settings and screenshots where relevant.

Support and bug reports are available in the dedicated Server Seeker section of the [Zazu's EyeBot Network Discord](https://discord.gg/TC4PhPx9sf). Zazuzin can also be found in the [BreakBlocks Discord](https://breakblocks.com/discord).
